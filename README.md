# ACPのコミュニケーション

心不全診療を中心とした、ACP（アドバンス・ケア・プランニング）の会話を支援する資料集です。

## ACPナビ（Webアプリ）

状況（非緊急ACP／緊急ACP）と場面を選ぶと、おすすめの進め方・そのまま使えるフレーズ・注意点・関連知識が表示されます。関連知識（4分割法、ICD停止、NURSE など27項目）はキーワードで検索できます。

- **開く**：GitHub Pages で公開しています（リポジトリの About 欄のリンク）。`index.html` をダウンロードしてブラウザで開けば、オフラインでも使えます。
- **印刷**：右上の「印刷」から、表示中の場面／ハンドブック／完全版／関連知識だけ、を選んで A4 で印刷できます。

| 非緊急ACP | 緊急ACP |
|---|---|
| 初めて話す | 本人と話せる（REMAP） |
| 節目での見直し | 本人が話せない（家族と） |
| 話したがらない・お任せ | 意見が割れる（4分割法） |
| デバイス治療を検討（ICD・LVAD） | 治療の効果が見込めない |
